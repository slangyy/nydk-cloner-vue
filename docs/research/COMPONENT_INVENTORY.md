# 组件清单

1. `SiteHeader.vue`：Logo、桌面导航、下拉菜单、搜索入口、移动菜单和滚动状态。
2. `HeroSection.vue`：本地视频首屏和单个分页点。
3. `SectionTitle.vue`：通用中英文标题、水印和短横线。
4. `HomeSystemsSection.vue`：八个系统卡、品牌中央卡和跨卡详情层。
5. `SpaceShowcase.vue`：六状态主图与响应式缩略轨道。
6. `DesignInstituteSection.vue`：设计师拼贴。
7. `CasesShowcase.vue`：五状态主图、说明和缩略轨道。
8. `NewsSection.vue`：四条新闻卡片和查看详情按钮。
9. `SiteFooter.vue`：品牌、社交、二维码、导航、联系与法律信息。
10. `PlaceholderView.vue`：同站未复刻路径的本地占位页。

所有组件均为 Vue SFC，使用 `<script setup lang="ts">`，不使用 JSX/TSX。
