# 南洋迪克首页设计令牌

## 颜色

- 页面背景：`#ffffff`
- 深棕背景：`#3c312f`
- 主文字：`#231815`
- 英文标题：`#634f44`
- 品牌强调色：`#bc9480`
- 移动导航背景：`#eeeeee`
- 次级文字：`rgba(35, 24, 21, 0.6)`
- 白色叠加文字：`#ffffff`
- 案例说明遮罩：暖棕黑半透明渐变
- 边框：`#d3d1d0`

## 字体

- 英文展示标题：本地 `Bank` 字体，来源为原站 TTF。
- 中文和正文：`Regular` 语义，实际回退为系统无衬线字体。
- 正文回退栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif`。

## 尺寸与间距

- 主内容容器：桌面 `width: 88%`，居中；移动 `width: 90%`。
- 通用内容段纵向留白：桌面约 `5vw`，移动约 `10vw`。
- 通用标题水印：桌面背景尺寸约 158px，1440px 下约 143px，移动约 80px。
- 通用标题短横线：桌面 66 × 4px，移动约 35 × 2px。
- 系统卡片：桌面 3 列、宽 32.8%、行间距 0.8%；移动 2 列。
- 导航切换断点：998px。
- 核心内容断点：1366、1200、998、768、390px。

## 动效

- Header 显示/隐藏与换色：`0.3s`。
- 系统卡展开：`0.6s ease-out`；详情文字额外延迟 0.2s、持续 0.7s。
- 空间和案例主图淡入：`0.8s ease-in/out`。
- 设计师与新闻图片 hover：`0.5s`，scale 1.04/1.05。
- 新闻按钮双色三角填充：`0.6s`。
- 进入视口：fadeInUp，约 `0.8s`。

## 媒体

- Hero：`object-fit: cover`，桌面 `100vh`，移动/平板 200px。
- Space/Cases：主图宽高比约 16:9，`object-fit: cover`。
- 新闻图片容器宽高比约 16:9，图片居中裁切。
- 已采集 60 个 img DOM 节点、47 个唯一图片 URL、3 个视频节点（1 个唯一视频）和 23 个 SVG 节点。
