# 设计系统页面规格

- 参考路径：`/design.html?p=0`
- Hero：`d71dbba5-5cfe-4077-a1bc-5967156d0b84.jpg`，标题
  `Design System / 设计系统`。
- 第一段使用 143px 高的本地 N 水印，36px 主标题以 0.6em 字距叠放在水印
  上，22px 副标题使用 0.3em 字距；标题块与九宫格相隔 115px。九张
  `480 × 288` 图片组成无缝的桌面三列矩阵。
- “原创设计”区桌面高度约为视口宽度的 `51.42%`，使用 1440px 内容容器。
  左侧文字占 48%，右侧主图容器占 45%；主图向右溢出到容器外。40 × 536px
  竖图贴页面左缘，340 × 340px 细节图从主图左下方交叠。标题为 52px，
  副标题为 36px 且字距 0.5em，正文为 18px、3.33 倍行高。
- “南洋迪克设计力”使用
  `79a1d919-60f3-4e42-a600-b74538c8bdde.jpg` 全宽背景，区块高度约为视口
  宽度的 `50.61%`，并与原创设计区保持约 `20vw` 的白色间隔。标题 52px，
  副标题 36px、字距 0.5em，分隔线 140px。正文为 18px、400 字重、
  3.6px 字距、59.94px 行高，宽度 44% 并自然换为两行。
- 进入动画：矩阵逐项向上；原创设计文字从左、主图从右、细节图从下进入；
  设计力文字向上淡入。所有动画支持 `prefers-reduced-motion`。
- `≤998px` 时原创设计改为文字与图片纵向排列，细节图保留左下交叠；设计力
  文案缩小并限制在 90% 宽度内。
