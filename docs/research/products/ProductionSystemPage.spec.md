# 生产系统页面规格

## 基准与范围

- 原站路径：`https://www.ny-dk.com/intelligence.html?p=1`
- 本地路径：`/intelligence.html?p=1`
- Hero：`PRODUCTION SYSTEM / 生产系统`
- 本规格覆盖“智造力”“工厂 / 设备”“环保 / 供应”三个正文模块。
- 页面继续使用现有 `ProductPageShell`、`InnerPageHero`、`SiteHeader` 和
  `SiteFooter`。

## 通用区块标题

- 三个标题均复用 `SectionTitle`，并保留现有本地 N 水印图片。
- 桌面标题容器约 `151px` 高；英文 `38px`，中文 `32px`。
- 移动标题容器约 `97px` 高；英文 `20px`，中文 `18px`。
- 原站水印图片本身包含短横线，因此本页隐藏 `SectionTitle` 额外生成的分隔线。
- “工厂 / 设备”使用白色文字和低透明度水印，其他标题使用深棕色文字。

## 智造力

- 桌面区块高约 `778px`，上下内边距分别为 `72px` 和 `115px`。
- 背景使用
  `b4ec228d-199d-4e66-86f7-8984b4c7734f.jpg`，居中铺满，不叠加额外渐变。
- 卡片轨道宽 `80vw`，在 1440px 视口下为 `1152px`；标题下间距约 `40px`。
- 桌面一次展示五张卡，卡宽约 `202px`、高 `399px`、间距 `35px`。
- 卡片外层为白色、圆角 `20px`、内边距 `10px`；内层为棕色低透明度虚线，
  同样圆角 `20px`，上下内边距 `45px`。
- 桌面卡片标题 `26px`，说明 `16px / 24px`，主题色 `#bc9480`。
- 图标 PNG 是上下两帧的精灵图，放在 `100 × 100px` 圆形裁切容器中；默认显示
  上半帧，悬停显示下半帧。
- 卡片悬停时背景在 `0.3s` 内变为 `#bc9480`，标题、说明变白，图标圆框变为
  `rgba(255,255,255,.3)`。
- 卡片间“＋”为 `50 × 50px` 白色圆按钮，带淡棕色阴影；最后一张卡不显示。
- 移动端轨道宽 `90vw`，一次展示两张卡，卡高 `361px`、间距 `10px`，
  支持触摸横向滚动。
- 移动端标题 `18px / 27px`，说明 `14px / 21px`，图标 `78 × 156px`。

## 工厂 / 设备

- 桌面区块高约 `597px`，顶部内边距 `72px`。
- 背景使用
  `27bcb19a-0d67-49ab-8acb-4f682dfdf21b.jpg`，
  `center top / contain no-repeat`，底色 `#faf8f7`，不加黑色遮罩。
- 标题和说明位于上方背景图内；轮播紧接其下并覆盖背景图底部，背景图结束后露出
  `#faf8f7` 底色。
- 说明文字桌面为 `20px / 30px`，宽 `90%`，标题下约 `29px`，轮播前约 `50px`。
- 轮播外层全宽；Swiper 本体宽 `60vw`，允许内容溢出。
- 桌面一次展示两张 `560:350` 图片，间距 `20px`；在 1440px 下单图约
  `422 × 264px`。
- 移动端一次展示一张，Swiper 宽 `60vw`；单图约 `231 × 144px`，
  两侧可看见相邻图片。
- 轮播循环、切换速度约 `800ms`，左右按钮位于页面两侧约 `10vw`。
- 原站初始化参数为 `loop: true`、`autoplay: true`；本地实现必须在首次渲染时
  同时填充左右两侧，不出现左侧空白，并默认每 `3000ms` 向左切换一张。
- 点击前后按钮或触摸滑动后自动播放继续运行。
- 原站初始化参数为 `loop: true`、`autoplay: true`；本地实现必须在首次渲染时
  同时填充左右两侧，不出现左侧空白，并默认每 `3000ms` 向左切换一张。
- 点击前后按钮或触摸滑动后自动播放继续运行。
- 图片悬停在 `0.5s` 内放大至 `1.05`；轮播按钮悬停变为 `#bc9480`，箭头变白。
- 减少动态效果时取消缩放过渡。

## 环保 / 供应

- 桌面区块上下内边距约 `86px`，内容宽 `80vw`。
- 标题与图文列表之间约 `46px`。
- 环保行高约 `399px`：
  - 左侧文字宽约 `37%`，左内边距为内容宽的 `5%`。
  - 右侧两图并排，分别保持 `380:500` 和 `1:1` 比例，间距约 `16px`。
- 供应行与上一行间距约 `57px`：
  - 左侧供应链图片宽约 `64%`，保持 `920:500` 比例。
  - 右侧文字右对齐，并保留右侧 `5%` 内边距。
- 小标题桌面 `32px / 48px`，正文 `20px / 30px`；标题下保留
  `60 × 2px` 棕色短线。
- 移动端内容宽 `90vw`，两行均为图片在上、文字在下：
  - 环保双图总高约 `192px`，两图间距约 `8px`。
  - 供应图片高约 `188px`。
  - 图文间距 `20px`，文字左右内边距 `5%`。
  - 小标题 `18px / 27px`，正文 `16px / 24px`，全部左对齐。
- 图像容器裁切溢出，鼠标悬停图片在 `0.5s` 内放大至 `1.05`。

## 动画与可访问性

- 标题和各行使用现有 IntersectionObserver 进入视口动画，只触发一次。
- 轮播按钮提供中文 `aria-label`，图片使用数据文件中的替代文本。
- 所有位移、轮播图片缩放在 `prefers-reduced-motion: reduce` 下取消过渡。
