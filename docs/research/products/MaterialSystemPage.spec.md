# 材料系统页面规格

## 基准与范围

- 原站路径：`https://www.ny-dk.com/material.html?p=5`
- 本地路径：`/material.html?p=5`
- Hero：`MATERIAL SYSTEMS / 材料系统`
- 本规格覆盖 `SUPPLY / 供应` 和
  `Multiple material selection / 多元选材` 两个正文区块。

## 公共标题

- 两处标题复用 `SectionTitle`，并使用本地 N 水印图片。
- 桌面标题容器按视口缩放，最大约 `201px`；英文最大 `48px`，中文最大
  `36px`。
- 移动端标题容器约 `105px`；英文 `20px`，中文 `18px`。
- 水印图片本身包含短横线，因此本页隐藏组件额外生成的分隔线。

## SUPPLY / 供应

- 交互模型：进入视口从下向上淡入；三组内容分别是标题、主图与文案、品牌墙。
- 区块顶部内边距为视口宽度的 `5.5%`。
- 区块顶部约 `82%` 高度使用 `#faf8f7` 背景，底部恢复白色。
- 内容容器宽 `80vw`，最大 `1440px`。
- 主图与文案组合在标题下方 `4%`：
  - 左侧主图宽 `64%`，使用
    `9ccf65a5-8fbd-4f38-bde9-1c60e784c289.jpg`。
  - 右侧文案宽 `35%`，顶部下移 `4%`。
  - 标题右对齐，下方为 `70 × 1px` 棕色短线；正文右对齐。
  - 品牌 Logo 图宽文案列的 `59.2%`，右对齐。
- 品牌墙绝对定位在内容容器高度的 `80%`：
  - 整体右对齐。
  - 第一张宽 `26.388%`，第二张宽 `35%`，间距 `1%`。
  - 与上方主图、文案产生原站相同的交叠。
- 主图及两张品牌墙均裁切溢出；悬停时在 `0.5s` 内放大至 `1.05`。
- 移动端：
  - 内容容器宽 `90vw`。
  - 主图宽 `100%`。
  - 文案宽 `100%`、上下内边距 `30px`，全部居中。
  - 品牌 Logo 居中。
  - 品牌墙回到正常文档流，宽度分别为 `43%` 与 `56%`。

## Multiple material selection / 多元选材

- 区块与供应区间距为 `13.5vw`，无额外背景色。
- 内容宽 `80vw`，最大 `1440px`。
- 拼贴区在标题下方 `5%`，由四个独立的向上淡入组组成。
- 桌面每组宽 `49.51%`，两组一行；组内间距约 `1.84%`。
- 四组排布：
  - 第一组：进口头层小牛皮横跨整行；智能感光镜与 LED 智能灯带并列。
  - 第二组：高密度通透玻璃和 Pu 环保漆在左侧上下排列；轻柔质感绒面在右侧纵向跨两格。
  - 第三组：高精度牛皮拼版在左侧纵向跨两格；铜质装饰和高级铝合金在右侧上下排列。
  - 第四组：皮质软包横跨整行；质感软包布面与岩板/奢石并列。
- 图片保持原始比例，不使用统一固定高度；卡片裁切溢出。
- 文案绝对定位于图片左下角，桌面最大 `24px`，移动端 `16px`，白色。
- 图片悬停在 `0.5s` 内放大至 `1.05`。
- 移动端四组全部改为 `100%` 宽，但组内跨行、并列关系保持不变。

## 动画与无障碍

- 所有进入动画使用现有 `ProductReveal`，方向为 `up`，每组只触发一次。
- `prefers-reduced-motion: reduce` 下取消位移和图片缩放过渡。
- 图片使用数据文件中的真实中文替代文本，不请求原站资源。
