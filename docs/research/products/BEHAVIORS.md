# 产品系统交互说明

## 共享行为

- Header 与 Footer 完全复用现有实现。
- Hero 中央标题挂载后停留 2 秒，再以约 0.6 秒淡出；面包屑始终显示。
- 正文元素首次进入视口时执行一次动画：
  - `fadeInUp`：`translateY(40px)` 到 `0`，透明度 `0` 到 `1`。
  - `fadeInLeft`：`translateX(-60px)` 到 `0`。
  - `fadeInRight`：`translateX(60px)` 到 `0`。
  - 时长约 `0.8s`，缓动 `ease-out`。
- `prefers-reduced-motion: reduce` 时直接显示最终状态，并关闭自动播放。

## 页面专属行为

- 生产系统：五项能力在窄屏横向滑动；设备图库使用循环轮播和前后按钮。
- 成品系统：七个标签点击切换对应图片；切换使用淡入；前后按钮作用于当前标签图库；图片查看层支持关闭、Esc 和焦点返回。
- 整装系统：十三张细节图为主轮播；会客、睡眠、入户标签切换对应空间图；图片查看层行为与成品系统一致。
- 服务系统：三项服务力循环展示，桌面显示主项和相邻视觉，移动端单卡。
- 所有轮播支持鼠标、触摸、键盘按钮操作，并避免在首尾出现空白。
