# 产品系统交互说明

## 共享行为

- Header 与 Footer 完全复用现有实现。
- Hero 中央标题挂载后停留 2 秒，再以约 0.6 秒淡出；面包屑始终显示。
- 正文元素首次进入视口时执行一次动画：
  - `fadeInUp`：`translateY(40px)` 到 `0`，透明度 `0` 到 `1`。
  - `fadeInLeft`：`translateX(-60px)` 到 `0`。
  - `fadeInRight`：`translateX(60px)` 到 `0`。
  - 时长约 `0.8s`，缓动 `ease-out`。
- `prefers-reduced-motion: reduce` 时直接显示最终状态，并关闭自动播放。

## 页面专属行为

- 生产系统：五项能力在窄屏横向滑动；设备图库使用循环轮播和前后按钮。
- 成品系统：七个标签点击切换对应图片；切换使用淡入；前后按钮作用于当前标签图库；图片查看层支持关闭、Esc 和焦点返回。
- 整装系统：门、墙、柜由三个同构路由承载，顶部精灵图切换条显示当前选中状态；正文分别使用 13、37、24 张高清图片进行全宽自动轮播。
- 服务系统：三项服务力循环展示，桌面显示主项和相邻视觉，移动端单卡。
- 所有轮播支持鼠标、触摸、键盘按钮操作，并避免在首尾出现空白。
# 成品系统交互补充（2026-07-30）

- 系列切换：六个系列使用真实 Vue Router 链接，共用一个页面组件，仅替换当前系列的数据、图片和选中态。
- 空间切换：点击底部空间项同步更新主图、中英文标题及详情图片；上一项、下一项均循环。
- 图片查看：点击当前空间或主视觉加号打开本地详情图片查看层，支持循环切换、遮罩关闭和 Escape 关闭。
- 过渡动画：主图使用约 0.8 秒淡入，系列图块与空间选中态使用约 0.3–0.5 秒过渡；`prefers-reduced-motion` 下取消非必要动画。
- 响应式：桌面保持横向系列导航和底部空间轨道，移动端允许横向滚动，不改变路由及状态语义。
