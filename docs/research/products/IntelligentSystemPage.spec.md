# 智能系统页面规格

- 参考路径：`/Zhijia.html?p=3`
- Hero：`ce8a6d2b-e662-4ca4-858e-db1750e9cc83.jpg`，比例 `2:1`，
  `INTELLIGENT SYSTEM / 智能系统`。
- 正文顶部留白约为视口宽度的 7%，内容容器为 1440px。
- 三组内容使用不同的非对称交错布局，组间距 144px：
  - “智家系统 智慧生活”：右对齐文字占 46%，左内距为容器的 6%；右图
    容器占 46%，图片以 136% 宽度向页面右缘溢出。
  - “私家大宅 科技生活”：左图占 46%；右侧文字占 45%，右内距为容器的
    5%，文字左对齐。
  - “智家浪潮 一触即发”：右对齐文字占 46% 并向上偏移约 8%；右图容器
    占 45%，图片以 120% 宽度向右溢出。
- 每组标题为一行 48px、700 字重；标题下方使用 `120 × 2px` 的玫瑰棕
  短线。右对齐标题的短线靠右，左对齐标题的短线靠左。
- 正文为 18px、`#777`、1px 字距、46.8px 行高。文案使用原站文本。
- 三组相邻图片在桌面鼠标悬停时于自身裁切框内放大至 `1.04`，过渡约
  `0.65s`；图片原有 136% / 100% / 120% 宽度关系保持不变。
- 尾图 `63e67b12-1e78-4771-93f5-66a3e36e2f92.jpg` 位于页面左侧，
  宽度为 `50vw`，最大 960px。
- 三组内容整体向上淡入；实现同时支持 `prefers-reduced-motion`。
- `≤998px` 时统一为图片在上、文字在下的单列布局，并取消图片溢出和文字
  负偏移；标题短线缩短为 64px。
- `prefers-reduced-motion` 下取消图片缩放过渡和悬停位移。
