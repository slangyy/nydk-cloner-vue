# 产品系统八页拓扑

## 共享页面壳

所有产品页按以下顺序装配：

1. 现有 `SiteHeader`，首屏透明覆盖，滚动行为保持项目现状。
2. `InnerPageHero`，全宽原图、中央 N 水印、英文/中文标题、底部面包屑。
3. 页面专属内容区。
4. 现有 `SiteFooter`。

桌面正文以 `1440px` 为内容上限，平板和移动端使用 `90%` 宽度。Hero 桌面按资源原始宽高比展示，`≤998px` 固定约 `300px`。

## 页面顺序

| 页面 | 正文区块 | 交互模型 |
| --- | --- | --- |
| 设计系统 | 九图矩阵 → 原创设计图文 → 设计力背景区 | 滚动进入动画 |
| 生产系统 | 五项能力 → 工厂设备轮播 → 团队指标 → 环保/供应 | 点击/触摸轮播 + 滚动进入 |
| 工艺系统 | 国际视野图文 → 极致工艺图文 → 全宽场景图 | 滚动进入动画 |
| 智能系统 | 三组交错图文 → 全宽场景图 | 滚动进入动画 |
| 成品系统 | 中英文介绍 → 七项空间标签 → 对应图库 | 点击标签、轮播、图片查看 |
| 材料系统 | 供应主视觉 → 十二项材料矩阵 | 滚动进入动画 |
| 整装系统 | 中英文介绍 → 十三图产品轮播 → 三项空间图库 | 点击标签、轮播、图片查看 |
| 服务系统 | 七步服务流程 → 三项服务力轮播 | 循环轮播 + 滚动进入 |
