# 南洋迪克首页行为说明

## Header

- 初始状态：固定顶部、透明背景；首页使用白色 Logo、导航文字和菜单线条。
- 页面下滚：Header 上移隐藏，移动距离约 120px。
- 页面上滚且不在顶部：Header 回到 `top: 0`，背景变为 `#eeeeee`，Logo 与图标切换深色。
- 回到顶部：恢复透明背景和白色版本。
- 桌面端产品/关于子菜单由 hover/focus 打开。
- `≤998px` 时显示汉堡按钮；打开后切换为 X，菜单从 50px 下方铺满视口。
- 产品与关于支持独立 accordion；切换路由、按 Escape 或关闭按钮时收起。

## Hero

- 单个逻辑视频，原站通过重复 Swiper slide 实现循环。
- Clone 使用单个本地视频 `muted autoplay loop playsinline`，不引入多余轮播状态。
- 底部保留一个白色分页圆点。

## 家装系统

- 桌面端 3 × 3：第五格为品牌卡，其他八格为系统。
- 桌面 pointer hover：详情图层从所在边向外扩展到两张卡宽；第三列向左展开，其他向右展开。
- `≤998px`：删除中央品牌格，变为 2 × 4；点击卡片展开，偶数列向左，奇数列向右，点击外部关闭。

## 空间展示

- 十个状态：入户、会客、餐厨、睡眠、衣帽、书茶、卫浴、阳台、康乐、典藏。
- 桌面 `>998px`：可见 6 项，支持 mouseenter、focus 和 click 切换。
- `521–998px` 可见 4 项，`≤520px` 可见 3 项；单行轨道支持原生横向触摸滑动，细箭头循环切换并自动居中活动项。
- 主图 active 状态 opacity 0 → 1，约 0.8s；缩略项 active 为暖棕色胶囊背景。
- 点击主图或圆形“＋”均打开当前空间图库，不再跳转成品系统页。
- 图库按 POSEENA → 砚山 → 磐石合并，显示系列、图片计数和缩略图。
- 图库支持循环前后切换、键盘方向键、Escape、触摸滑动、原图独立全屏和关闭后焦点恢复。
- 主图可通过 `children` 配置百分比锚点及嵌套详情图；详情支持轮播或并排模式，关闭详情后焦点返回锚点。
- 主图库和 `carousel` 详情层支持鼠标滚轮切换：向上滚动显示上一张，向下滚动显示下一张；单次连续滚轮或触控板手势仅切换一张。
- 入户空间原第 5、6 张作为原第 7 张的锚点详情，不进入主轮播；主轮播重新连续编号为 5 张。
- 会客空间第 13 张配置两个并列详情锚点：细节1展示原第 14、16 张，细节2展示原第 15、17 张；四张详情图不进入主轮播。

## 案例

- 五个状态，点击缩略图切换；不自动播放。
- 主图、说明与缩略 active 状态同步。
- 主图 opacity 0 → 1，约 0.8s。
- 缩略图默认 opacity 0.2；active/hover opacity 1，active 带 `#bc9480` 边框。
- 前后按钮只控制缩略轨道的可视范围。

## 新闻与页脚

- 新闻卡图片 hover scale 1.05。
- “查看详情”按钮 hover 由两侧三角形填满暖棕色，并将文字变白。
- 移动端新闻为两列；页脚隐藏主导航列，仅保留品牌、社交、二维码、联系方式和法律信息。

## Reduced Motion

- `prefers-reduced-motion: reduce` 时禁用大幅位移动画、缩短过渡，并确保内容直接可见。
