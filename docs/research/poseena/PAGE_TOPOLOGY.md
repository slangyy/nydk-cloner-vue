# ExtremeSystem / POSEENA Page Topology

Reference URL: `https://www.ny-dk.com/ExtremeSystem.html`

1. Shared fixed `SiteHeader`, transparent at scroll position 0 and solid after leaving the hero.
2. `PoseenaHero`: 1920×960 mountain/architecture image, breadcrumb anchored to the lower edge.
3. `PoseenaStorySection`: centered brand origin copy and Louvre panorama, followed by the light-pattern “意为光芒” split layout.
4. `PoseenaMentorsSection`: rose-pattern background and two black mentor cards. Desktop hover changes the expanded card; mobile shows both cards fully.
5. `PoseenaStrategySection`: light-pattern background, overlapping the preceding section, with three 1+1+6 cards.
6. `PoseenaPursuitSection`: white split layout for the five “极致” values.
7. `PoseenaProductSystemSection`: edge-to-edge 50/50 image and copy layout.
8. `PoseenaCasesSection`: centered looping Swiper with three store/project cases.
9. Existing local `SiteFooter`; the original page footer is intentionally out of scope.

The document uses normal browser scrolling. Content enters with one-shot fade-up/side animations. No video, sticky content, scroll snap, canvas, or time-driven content was detected.
